# MySQL-Python-Practice

This repository contains my Python and MySQL practice programs using PyMySQL.

# Topics Covered

1. MySQL Connection and SELECT
2. Multiple SELECT Queries
3. INSERT Operations
4. UPDATE Operations
5. DELETE Operations
6. Searching and Filtering Data

# Files

- `01PyMySQL_ConnectSelect.ipynb` - MySQL connection and SELECT operations
- `02PyMySQL_moreselect.ipynb` - More SELECT queries
- `03PyMYSQL_Insert.ipynb` - INSERT operations
- `04pymysql_update.ipynb` - UPDATE operations
- `05MySQL_Delete.ipynb` - DELETE operations
- `06PyMySQL_Searching.ipynb` - Searching and filtering records

#Technologies Used

- Python
- MySQL
- PyMySQL
- Google Colab
- Jupyter Notebook

# Purpose

The purpose of this repository is to practice database operations using Python and MySQL and to build practical SQL skills.
